# Bootstrap CSS užduotis

Atkartotas faile `bootstrap_uzduotys_2026.pdf` pateiktas maketas: pasveikinimo blokas su mygtuku, trys vienodi teksto ir nuotraukos stulpeliai bei žalia apatinė juosta. Nors Moodle aprašyme minimi trys pavyzdžiai, pridėtame vieno puslapio PDF yra vienas maketas su trimis stulpeliais.

## Atidarymas ir pateikimas

Atidarykite šio aplanko `index.html` naršyklėje. PHP, XAMPP ir interneto nereikia. Norėdami pateikti darbą, ZIP formatu supakuokite visą `bootstrap-uzduotis` aplanką, įskaitant `css` ir `images`, ir įkelkite į Moodle.

Naudojamas vietinis Bootstrap 3.4.1 CSS failas (MIT licencija; autoriaus nuoroda išsaugota failo pradžioje). Ši versija atitinka mokomojoje medžiagoje `bootstrap.pdf` pateiktą Bootstrap 3 tinklelio sintaksę. Pagrindinės klasės: `container`, `row`, `col-sm-4`, `jumbotron`, `text-center`, `btn`, `btn-primary`, `btn-lg`, `btn-block`, `img-responsive`, `img-thumbnail`, `alert`, `alert-success`.

Nuo 768 px pločio rodomi trys stulpeliai, mažesniuose ekranuose jie išdėstomi vienas po kitu. Mygtukas „Learn more“ perkelia į nuotraukų skiltį. Pavyzdžio tekstas paliktas anglų kalba, kad atitiktų maketą. Nuotrauka iškirpta iš pateikto mokomojo PDF; išorinė lorempixel.com paslauga nenaudojama.

`css/style.css` tik patikslina šriftų dydžius, spalvas ir tarpus. JavaScript šiam statiniam puslapiui nereikalingas.
